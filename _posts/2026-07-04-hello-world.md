This is a sample post so the blog isn't empty. Delete this file
(`_posts/2026-07-04-hello-world.md`) whenever you like.

To write a new post, add a Markdown file to the `_posts` folder named
`YYYY-MM-DD-some-title.md` with this at the top:

    ---
    layout: post
    title: "Your title here"
    ---

Then write in plain Markdown below it. Push to GitHub and the blog
index updates itself.
